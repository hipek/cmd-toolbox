# AGENTS.md

## Agent Instructions

### Building
```bash
make build
```

### Installing
```bash
make install
```

### Cleaning
```bash
make clean
```

## Rules

- **Do not edit `**/SPEC.md` files** unless the user explicitly asks you to.
- **When creating a new project in this mono repo**, ensure orthogonal implementation — Rust files go to `<project-name>/src` directory (e.g. `video-project-creator/src`).
